# 转录产品重设计验收 · 2026-09-08

## 本轮变更

定位从内容管理回到音视频转文字。首页直接贴链接或上传，记录留在侧栏；结果页默认阅读原文。配色与排版参考 Claude 官网，不使用其品牌资产；用渐进呈现组织低频功能。

- 新入口：`static/workbench/transcribe.html/css/js`。
- 去掉专注模式、反复出现的副标题、常驻成功横幅和整排管理按钮。
- 复制在原按钮显示 1.8 秒，普通成功提示 2.6 秒自动消失。
- 标题原位编辑；破坏性/高成本操作使用应用内 dialog，禁用浏览器 prompt/confirm。
- 上传拖放、语言选项、请求幂等、旧链接和任务结果持久化继续复用原 API。
- 手机隐藏式侧栏隔离键盘焦点；正文保留单栏阅读布局。

- 390px 手机首页和结果页无横向溢出；侧栏搜索、打开记录、返回新转录正常。
