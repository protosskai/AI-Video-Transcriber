# 内容工作台 v2 第一阶段验收

日期：2026-09-08。此记录描述独立测试版本，不代表生产已经切换。

## 交付范围

- 内容库与执行历史分离；重试保留旧结果，旧任务链接兼容。
- URL 规范化去重、文件内容哈希去重、请求回执幂等。
- 提交即时反馈、上传进度、刷新恢复、断线保留结果并自动恢复同步。
- 标题搜索、状态筛选、修改标题、归档、回收站、恢复、取消排队。
- 文稿类型切换、目录、专注阅读、字号/外观、MD/TXT 导出。
- 不含文稿编辑、时间戳播放、Word/PDF、批量处理、多用户隔离、运行中取消。

## 自动测试

```sh
docker run --rm --network none transcriber-workbench:20260908-v2 \
  python -m unittest discover -s tests/task_center -v
```

20/20 通过：原 12 项回归 + 8 项内容库测试，包括并发请求、取消/领取竞争、上传重复文件清理、迁移幂等、软删除、旧成果导出、响应丢失后的请求回执。

没有使用生产数据运行写入测试，也没有再次调用付费模型做完整音视频转录。上游处理流水线本轮未修改；运行了已有适配层契约测试。独立验收 web 不启动 worker，因此执行器离线提示是预期行为。

## 浏览器验收

使用 Playwright CLI，独立端口 18002、合成文稿与测试任务。

已验证：

1. 新建 URL 请求在服务器接收后模拟响应丢失，页面给出错误，再次提交只保留一条记录。
2. 失败任务点击重试后模拟响应丢失，后台只有一个新执行；刷新可看到排队状态及上次保留的原文。
3. 取消排队、归档/移回、回收站/恢复均有可见反馈；文稿保留。
4. MD/TXT 下载接口返回正确原文；原文中的 HTML 不创建 script 元素。
5. 1440px 桌面、390px 手机布局与深色模式；手机无页面横向溢出，可返回列表并按标题查找。
6. 模拟浏览器断网，错误提示出现但已读文稿保留；恢复网络后错误提示自动消失。

重放时先启动独立容器，再用 `TC_ACCEPTANCE=1` 执行 `tests/task_center/seed_ui.py`。该脚本会修改其所在容器内的验收任务，禁止在生产容器执行。

## 真实历史数据的迁移演练

通过 SQLite backup API 从生产只读连接生成一致性快照，再对独立副本运行 `tests/task_center/check_production_copy.py`。

- 5 个原执行记录形成 4 份内容：原任务和其显式 retry 归为同一份内容，独立提交不擅自合并。
- `jobs/events` 全字段逐行比对，迁移前后完全一致。
- 所有原任务 ID 都能解析到内容记录。
- 原生产数据库未运行新 schema 迁移。

## 发布与回滚边界

本轮未 commit/push，也未替换生产容器。正式切换前须获得部署授权：确认队列空闲，SQLite 一致性备份，记录旧 image/env，然后仅更新应用 web/worker。Cloudflare Tunnel、SSH、Clash 均不改。

迁移仅增加表，旧 jobs/events 保留。应用回滚优先切回旧镜像，不可拿验收数据库覆盖生产；如恢复备份须先评估备份之后产生的数据。
